# Prompt 01 — Fundação Laravel e qualidade do repositório

Leia `docs/PROJECT_PLAN.md`, `docs/DECISIONS.md` e as regras `.cursor/rules/*.mdc`.

## Tarefa
Prepare a fundação do Arcana Tarot. Se o Laravel ainda não existir, crie a aplicação compatível com Laravel 13 e PHP 8.4. Se já existir, preserve a aplicação e ajuste somente o necessário.

- Configure `.env.example` sem credenciais reais.
- Configure Vite para CSS e JavaScript.
- Garanta scripts claros de instalação, execução e testes.
- Configure PHPUnit ou Pest conforme a escolha compatível com o projeto.
- Crie uma estrutura mínima de documentação em `docs/`.
- Configure `.gitignore` e verifique se `.env`, chaves, dumps e arquivos temporários não serão versionados.
- Não crie ainda os módulos de negócio.

## Verificações
- Instalação/validação de dependências.
- Teste básico da aplicação.
- Build do frontend, se o ambiente permitir.

Não avance para o prompt seguinte. Relate comandos e resultados reais.
