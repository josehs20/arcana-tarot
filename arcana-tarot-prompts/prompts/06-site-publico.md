# Prompt 06 — Página inicial e perfis públicos

Implemente as páginas públicas do Arcana Tarot usando Blade e Bootstrap.

## Páginas
- Página inicial com hero, chamada para ação, como funciona e lista de profissionais disponíveis.
- Listagem de profissionais.
- Perfil público do profissional.
- Login/cadastro integrados ao fluxo de autenticação existente.
- Botão/CTA visível **Trabalhe conosco** na página inicial, com destino à página de candidatura implementada no Prompt 07.
- Rodapé com links para termos, privacidade e contato; se páginas jurídicas completas não estiverem prontas, criar placeholders claramente identificados para revisão, sem inventar políticas definitivas.

## Cartão do profissional
Mostrar somente dados públicos aprovados: foto opcional, nome profissional, apresentação curta, especialidade, preço por minuto e status atual. Não expor e-mail, dados financeiros ou informações privadas.

## Regras
- Visitantes podem navegar, mas precisam autenticar-se para solicitar consulta.
- Exibir status e preço obtidos do servidor.
- Criar estados vazios quando não houver profissionais online.
- Não adicionar avaliações, agenda, blog, favoritos ou filtros complexos.
- O botão "Trabalhe conosco" deve combinar com o design premium, ser acessível e visível também em telas móveis; não deve prometer aprovação automática.
- Garantir responsividade e acessibilidade.

Criar testes de acesso às páginas e de não exposição de dados privados. Não avance além desse módulo.
