# Prompt 05 — Design system e layouts Blade

Crie a base visual premium/mística do Arcana Tarot usando Blade, Bootstrap 5.3, Vite e JavaScript simples. Não introduza React ou Vue.

## Direção visual
- Elegante, mística e premium, sem excesso de ornamentos.
- Azul-noite/escuro como base, roxo profundo como apoio, dourado discreto para destaque e marfim para texto.
- Títulos com Cormorant Garamond ou Cinzel; textos com Inter ou Manrope, com fallbacks.
- Layout responsivo, acessível e com contraste adequado.
- Animações discretas e respeitosas a `prefers-reduced-motion`.

## Implementar
- Layout público.
- Layout autenticado compartilhado.
- Layout do painel administrativo.
- Navegação adaptada para celular.
- Componentes Blade reutilizáveis para botões, cards, alertas, badges/status, campos e estados vazios.
- Estados online/offline/ocupado sempre com texto além da cor.
- Páginas de erro básicas e mensagens de validação.
- Identidade consistente sem exigir imagens externas obrigatórias.

Não implemente ainda todas as telas de negócio. Documente a paleta e os componentes em `docs/DESIGN_SYSTEM.md`. Execute o build Vite e corrija erros.
